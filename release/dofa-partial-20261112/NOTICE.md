# Data and software credits

The tests contain synthetic examples only. The numerical records
contain terrain labels and saved model predictions, without images or weights.
Code is by Kevin Lee. Parsing, inventory and fresh-output patterns adapt the
CETUS loss-normalization companion; its anonymous-author MIT notice is retained
in LICENSE together with the public author's notice.

Terrain labels derive from Lopes et al. (2020) and “Titan Global Map Shapefiles,”
contributed by Ashley Schoenfeld to Mendeley Data, version 1:
https://data.mendeley.com/datasets/f6jrtyfp66/1.
The dataset is licensed under Creative Commons Attribution 4.0:
https://creativecommons.org/licenses/by/4.0/.
The vector map was rasterized to assign classes to SAR image tiles.

The experiments use the Cassini SAR HiSAR Global Mosaic 351 m. Credit the
Cassini SAR Team, Jet Propulsion Laboratory and USGS Astrogeology Science Center.
This numerical package contains no mission imagery, upstream model source or
model weights. LICENSE covers the accompanying software and does not replace
the label-data terms above.
