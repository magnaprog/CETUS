# Source data terms and attribution

Source terms for the catalog metadata and result files.

## USGS/NASA Cassini RADAR

Product: Cassini SAR HiSAR Global Mosaic 351 m. The product record requests
citation. Attribute the Cassini SAR Team, Jet Propulsion Laboratory, and USGS
Astrogeology Science Center.

## NASA/JPL Magellan

Product: Magellan SAR FMAP right look global mosaic. The product record lists
public-domain access and no use constraints. Cite the product and the Magellan
mission (Saunders et al. 1992).

## Cassini VIMS+ISS mosaic

The Titan catalog contains transformed display samples from the Titan VIMS and
ISS Global Mosaic. It is BSD 3-Clause licensed. Retain the complete notice in
`THIRD_PARTY_NOTICES.md`, and cite Le Mouelic et al. 2019 and DOI
10.22002/D1.1173.

## Copernicus Sentinel-1

Sentinel-1 GRD inputs were processed into calibrated sigma0 tiles. The
Copernicus legal notice permits reproduction, distribution, communication, and
adaptation of the data. Required notice: "Contains modified Copernicus Sentinel data 2026."

## Copernicus DEM GLO-30 terrain correction

Terrain correction used ESA SNAP 13.0.0's "Copernicus 30m Global DEM" selector,
which maps to the Copernicus DEM GLO-30 public COG collection, licensed as
Copernicus WorldDEM-30 (COP-DEM-GLO-30-F). The exact collection release and
versions of individual tiles were not recorded. The product DOI is 10.5270/ESA-c5d3d65.
Retain the WorldDEM-30 notice in `THIRD_PARTY_NOTICES.md`.

## Lopes et al. 2020 terrain map

Source record: "Titan Global Map Shapefiles," Mendeley Data, version 1,
contributor Ashley Schoenfeld, data.mendeley.com/datasets/f6jrtyfp66/1. The
source is licensed CC BY 4.0: creativecommons.org/licenses/by/4.0/. Source
vector labels were rasterized into class labels for each tile and catalog
metadata. Cite the dataset and Lopes et al. 2020 when using those labels.
